# Inventário Drogaria Max - Filial 01

Repositório destinado à gestão, tratamento e importação de dados de inventário da Filial 01.

## Estrutura do Repositório
* `app.py`: Script principal em Python para gerar e processar a importação dos dados.
* `inventario_farmacia_filial01.csv`: Arquivo estruturado em CSV pronto para importação em sistemas de gestão/farmácia.
